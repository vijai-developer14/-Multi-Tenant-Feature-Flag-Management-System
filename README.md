# Feature Flag Management System

## Tech Stack
- Backend: Node.js, Express, MongoDB
- Frontend: React (Vite) x3

## Setup
1. Clone the repo
2. cd back-end && npm install
3. Create .env file with:
   - MONGO_URI=
   - PORT=5000
4. npm run dev
